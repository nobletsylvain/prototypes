# Sous la lame — étude de coupe V02

Démo mobile autonome : [jouer](index.html) · [documentation](documentation.html).

## Portée

Geste de coupe, réactions visuelles, miettes et sons à comparer. Sources 100/250 g et portions 4/8 g ; matière et identités conservées. Trois profils de résistance et six matières indépendants. Aucune économie ni progression ajoutée ; aucune intégration Unity.

## Essai tactile

Activer les sons, maintenir le bouton de coupe puis relâcher. Faire glisser sur la planche pour pousser les morceaux. Comparer Franche, Dense et Souple, puis les retours désactivés ; le ralenti sert à examiner le mouvement.

## Vérification

64 contrôles de la démo passent. Les six scripts de la V02 restent identiques dans la version mobile. Syntaxe des sept scripts, liens, identifiants et déplacement des boutons vérifiés. Les images de documentation sont calculées depuis les commandes de dessin ; aucun essai humain de V02 ni écoute n'est revendiqué.
